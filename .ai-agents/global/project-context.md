# MUZILLA - Контекст проекта

## Архитектура проекта
```
mz/
├── main/          # Laravel 12 бэкенд с Inertia.js (основной сервис аутентификации)
├── nuxt/          # Nuxt 3 фронтенд с Sanctum auth + PrimeVue
├── discogs/       # Laravel бэкенд для сервиса Discogs API
└── old/           # Устаревший проект (НЕ ТРОГАТЬ)
```

## Технологический стек
- **Backend**: Laravel 12 + PHP 8.2 + SQLite + Laravel Sanctum
- **Frontend**: Nuxt 3 + Vue 3 + TypeScript + PrimeVue + Tailwind CSS
- **База данных**: SQLite для разработки
- **Аутентификация**: Laravel Sanctum (stateful SPA режим)
- **Тестирование**: Pest (Laravel) + Vitest (Nuxt)
- **API интеграция**: Discogs API для музыкальных релизов

## Специфика MUZILLA
- Маркетплейс музыкальных инструментов и оборудования
- Система продуктов с категориями и подкатегориями
- Интеграция с Discogs для поиска музыкальных релизов
- Мультимедиа поддержка (фото товаров + видео YouTube/RuTube/VK)
- Аукционная система для товаров
- Система рейтингов качества (винил, упаковка, устройства)

## Запущенные сервисы (НЕ ПЕРЕЗАПУСКАТЬ!)
- Laravel main: http://localhost:8000
- Laravel discogs: http://localhost:8001
- Laravel Reverb: http://localhost:8080
- Nuxt frontend: http://localhost:3000

## Критические модули
- **Аутентификация**: Laravel Sanctum с CSRF защитой
- **Продукты**: Система каталога с категориями
- **Discogs**: Интеграция для поиска релизов
- **Медиа**: Загрузка фото/видео товаров
- **Аукционы**: Система торгов по времени

## Безопасность
- CSRF токены для всех форм
- Middleware аутентификации для защищенных роутов
- Валидация на backend И frontend обязательна
- Санитизация пользовательских данных
