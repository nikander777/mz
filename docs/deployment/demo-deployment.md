# 🎵 Быстрое развертывание демо-данных MUZILLA

Этот файл содержит инструкции для быстрого развертывания демо-данных для демонстрации функциональности MUZILLA.

## Команды для развертывания

### Полное развертывание с нуля
```bash
cd main
php artisan migrate:fresh --seed
```

### Запуск только демо-сидера (если база уже настроена)
```bash
cd main
php artisan db:seed --class=DemoSeeder
```

## Особенности данных

### Типы пользователей
- **Коллекционеры** (`is_collector = true`)
- **Продавцы** (`is_seller = true`)
- **Покупатели** (`is_buyer = true`)
- **Магазины** (`is_store = true`)
- **Коммерческие** (`is_commerce = true`)

### Состояния товаров
- Новый (`new`)
- Б/У (`used`)
- Коллекционный (`collectible`)

### Качества состояний
Система оценки качества от Mint (отличное) до Poor (плохое):
- Mint (M), Near Mint (NM), Excellent, Very Good Plus (VG+), Very Good (VG), Good Plus (G+), Good (G), Fair, Poor
