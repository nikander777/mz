# Справочник статусов

> Все статусы, встречающиеся в заказах и выплатах, в одном месте. Используется при согласовании флоу и в тестировании.

## Статус заказа

| Статус | Значение |
|---|---|
| На рассмотрении | Заказ создан, ждёт оплаты |
| Подтверждён | Подтверждён покупателем, ожидается оплата |
| Ожидает подтверждения продавца | Оплачен, идёт окно продавца 48 ч |
| Подтверждён продавцом | Готовится к отправке (создана накладная/QR) |
| Отправлен | Передан в доставку |
| Доставлен | Получен покупателем |
| Завершён | Финал: получен, инициирована выплата продавцу |
| Отменён | Отменён (в т.ч. автоотмена по таймауту) |
| Возврат средств | Выполнен возврат покупателю |
| Спор | Открыт спор, ждёт решения модератора |

Подробнее о переходах — [Заказы: жизненный цикл](/overview/orders).

## Статус оплаты

| Статус | Значение |
|---|---|
| Не оплачено | Оплата ещё не проводилась |
| Ожидание | Платёж инициирован, ждём подтверждения |
| Оплачено | Деньги на счёте площадки |
| Ошибка | Оплата не прошла |
| Возврат | Средства возвращены покупателю |

## Статус доставки

| Статус | Значение |
|---|---|
| Ожидает отправки | Отправление ещё не создано |
| Готово к отправке | Накладная/QR сформированы |
| Отправлено | Передано перевозчику |
| В пути | Едет |
| Прибыло в ПВЗ | Ждёт получения в пункте выдачи |
| Доставлено | Получено покупателем |
| Возврат | Возвращается отправителю |
| Отменено | Отправление отменено |
| Ошибка | Ошибка создания отправления |

## Статус выплаты продавцу

| Статус | Значение |
|---|---|
| Не начата | Заказ ещё не завершён / условия не выполнены |
| В обработке | Выплата инициирована |
| Выполнена | Деньги ушли продавцу |
| Ошибка | Выплата не прошла (повтор по расписанию) |

Подробнее — [Выплаты продавцу](/overview/payouts).
