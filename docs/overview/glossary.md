# Глоссарий

> Короткий словарь терминов MUZILLA — для быстрого понимания документации.

## Бизнес и роли

| Термин | Значение |
|---|---|
| **C2C** | Продают и покупают сами пользователи, площадка — посредник |
| **Покупатель / Продавец** | Роли пользователя; один аккаунт может быть и тем, и другим |
| **Витрина** | Публичный профиль продавца с его товарами |
| **Транзитный счёт** | Счёт площадки, где деньги удерживаются между оплатой и выплатой |
| **Комиссия площадки** | Удержание MUZILLA с суммы заказа |
| **Выплата** | Перевод денег продавцу после завершения заказа |
| **Спор** | Оспаривание сделки покупателем; замораживает выплату |

## Заказы и доставка

| Термин | Значение |
|---|---|
| **Окно подтверждения (48 ч)** | Срок, за который продавец подтверждает оплаченный заказ |
| **Удержание выплаты (48 ч)** | Защитный период после доставки до выплаты продавцу |
| **Автоотмена** | Отмена оплаченного заказа, не подтверждённого за 48 ч (с возвратом) |
| **Автозавершение** | Перевод доставленного заказа в «Завершён» через 48 ч |
| **ПВЗ** | Пункт выдачи заказов (СДЭК / отделение Почты) |
| **Грейд** | Оценка состояния носителя (Mint / Near Mint / … / Poor) |

## Каталог и дискография

| Термин | Значение |
|---|---|
| **Дискография** | Справочный каталог из базы Discogs (артисты, релизы, мастера, лейблы) |
| **Релиз** | Конкретное издание альбома |
| **Мастер** | Обобщённая запись альбома, объединяющая все его издания (версии) |
| **Фасеты** | Счётчики фильтров в каталоге (сколько товаров подходит) |

## Партнёры и техника

| Термин | Значение |
|---|---|
| **МОНЕТА** | Платёжный провайдер: приём оплаты, счёт, выплаты |
| **СБП** | Система быстрых платежей (оплата по QR/ссылке) |
| **СДЭК / Почта России** | Перевозчики |
| **Discogs** | Внешняя база дискографии |
| **P0 / P1 / P2** | Приоритеты тестирования: ядро / важное / второстепенное |
