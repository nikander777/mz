# Карточка товара

> Страница конкретного товара продавца: что на ней показано, что может сделать покупатель и как система реагирует на каждое действие. Технические детали — приложение [Техническая справка → Каталог и поиск](/processes/catalog-search).

## Назначение

Карточка товара — точка принятия решения о покупке. Показывает фото, характеристики, цену, информацию о продавце, похожие товары и отзывы. Страница публичная (рендерится на сервере для SEO), плюс есть приватный режим предпросмотра для владельца скрытого товара.

Товары бывают двух типов: **«музыка»** (винил, CD, кассеты) и **«Hi-Fi»** (аппаратура). Тип определяется автоматически по категории товара и меняет набор характеристик и вкладок.

## Роли и что видит каждый

| Роль | Что доступно |
|---|---|
| **Гость** (не авторизован) | Полная карточка, галерея, характеристики, продавец, вкладки. Избранное и корзина работают локально (сохраняются в браузере). «Написать продавцу» ведёт в раздел сообщений, где сработает требование авторизации |
| **Покупатель** (авторизован) | То же + корзина и избранное через аккаунт, переписка с продавцом |
| **Владелец товара** | Обычная страница для активного товара; для скрытого/неактивного — режим предпросмотра `?preview=1` с плашкой «Товар скрыт с продажи» и заблокированной кнопкой «В корзину» |

Продавец в карточке — это субъект блока справа: рейтинг, «был на сайте», город, кнопки связи.

## Как открывается страница

Адрес карточки — человекочитаемый (slug вида `catalog/product/artist-title-...`). Система умеет находить товар по нескольким видам ссылок и корректно перенаправлять на канонический адрес:

1. **Точный текущий адрес** — товар открывается сразу.
2. **Устаревший адрес** (название товара изменилось, старый slug) → редирект 301 на актуальный адрес.
3. **Старые ссылки из прежней системы** (числовой идентификатор старого сайта, отдельная таблица легаси-адресов) → редирект 301.
4. **Числовой идентификатор товара** → редирект 301 на канонический slug.
5. **Несуществующий товар** → страница «Товар не найден» (404).

Редиректы бесшовны для пользователя: старые ссылки из поисковиков и закладок продолжают работать.

::: warning Внимание
При переносе каталога товары будут недоступны, пока продавцы не укажут базовый ПВЗ, а также не подтвердят аккаунт продавца через монету. Ввиду этого часть товаров все же будут не доступны.
:::

## Что показано

- **Шапка:** название, счётчик просмотров, «Поделиться», «В избранное». Для владельца скрытого товара — плашка «Товар скрыт с продажи» (режим предпросмотра).
- **Галерея** фотографий: главное фото + стрелки перелистывания по кругу (стрелки появляются только если фото больше одного). Если своих фото нет — берутся изображения релиза из дискографии (до 4), если и их нет — заглушка. Отдельной панели миниатюр нет.
- **Характеристики.** Для **музыки**: лейбл, исполнитель, жанр, стиль, страна, год релиза, формат, каталожный номер, ссылка «Перейти на страницу релиза» (в дискографию). Лейбл и исполнитель кликабельны — ведут на страницу дискографии, **но только в случае, если товар привязан к релизу**. Для **Hi-Fi**: бренд, категория, год выпуска (текстом), технические характеристики. Цена + «доставка от N ₽», наличие «N шт».
- **Блок продавца** (правая колонка): название магазина (ссылка на профиль) + значок верификации + кнопка-инфо «i» (открывает окно о магазине), дата публикации, рейтинг со звездой и числом отзывов (клик прокручивает к отзывам), «Продавец был на сайте», «Город отправки» (ссылка на каталог с фильтром по городу).
- **Вкладки** (формируются динамически, лишние не показываются):
  - **Описание** — если у товара или продавца есть текст описания.
  - **Качество товара** — состояние носителя, обложки/упаковки, устройства (для Hi-Fi), комментарий.
  - **Доставка и оплата** — способы доставки и условия возврата.
  - **Содержание** — треклист (только для музыки).
  - **Отзывы о продавце** — список отзывов.
- **Похожие:** «Другие товары этого продавца» и «Похожие товары» (по исполнителю → подкатегории → категории). Пустые блоки скрываются.

::: warning На согласование
1. Блок доставка от N руб. - перешедший по "наследству" блок с МЗ 1.0. На старом портале продавец в карточке указывал стоимость доставки и эта информация отображалась в карточке. Сейчас у нас все завязано на API, в связи с этим считаем что это избыточно, так как для реальной реализации этой фичи нам необходимо на каждое открытие товара просчитывать стоимость доставки + мы можем посчитать доставку, только в случае если у покупателя задан ПВЗ по умолчанию.
2. Значок верификации - как продавец его получает? По логике - все продавцы портала верифицированные юр.лица / ИП. Нужно уточнение по реализации. 
3. Так как МЗ 2.0 выступает гарантом доставки и оплаты, то предполагаем, что для этой вкладки нужно подготовить готовый текст.
:::

## Действия покупателя

- **«В корзину»** — добавляет 1 шт. У гостя корзина хранится в браузере, у авторизованного — в аккаунте. Кнопка меняет текст: «В корзину» → «В корзине (N)». Блокируется при отсутствии остатка, при режиме предпросмотра скрытого товара и когда в корзине уже всё доступное количество.
- **«В избранное»** (сердечко) — работает и у гостя (локально), и у авторизованного. Повторный клик убирает из избранного.
- **«Написать продавцу»** — переход в сообщения по этому товару (`/messages?seller=…&product=…`). Гостя там встретит требование авторизации.
- **«Поделиться»** — системное окно «Поделиться» либо копирование ссылки в буфер обмена.
- Перейти в профиль продавца, на страницу релиза в дискографии, в окно с информацией о магазине.

## Уведомления

Страница показывает только всплывающие подсказки (тосты). Серверных писем/пуш-уведомлений на этой странице нет.

| Событие | Текст | Цвет |
|---|---|---|
| Товар добавлен в корзину | «Товар добавлен в корзину» | зелёный |
| Достигнут лимит остатка | «Товар уже в корзине, макс: N шт» | оранжевый |
| Ошибка добавления в корзину | сообщение об ошибке | красный |
| Добавлено/убрано из избранного | «Добавлено в избранное» / «Удалено из избранного» | зелёный |
| Ошибка избранного | «Не удалось обновить избранное» | красный |
| Скопирована ссылка | «Ссылка скопирована» | зелёный |

## Все сценарии и крайние случаи

| Ситуация | Что происходит |
|---|---|
| Активный товар, продавец допущен к продажам | Полная карточка, счётчик просмотров растёт |
| Товар скрыт/черновик/продан, публичный вход | Страница «Товар не найден» (404) |
| Продавец не прошёл проверку (нет допуска) | 404, даже если товар активен |
| Товар удалён (soft-delete) | 404 |
| Владелец, `?preview=1`, скрытый товар | Режим предпросмотра: плашка «Товар скрыт», кнопка «В корзину» заблокирована, просмотры **не растут** |
| Владелец пытается смотреть предпросмотр чужого товара | Отказ в доступе (403) |
| Устаревший/легаси-адрес, числовой id | Редирект 301 на канонический адрес |
| Несуществующий товар | 404 |
| Остаток = 0 | «Нет в наличии», кнопка заблокирована |
| Нет своих фото | Показ фото релиза, иначе заглушка |
| Музыка без привязки к дискографии | Нет ссылок на исполнителя/лейбл, «Треклист не указан», исполнитель «Неизвестен» если пусто |
| Hi-Fi товар | Нет вкладки «Содержание», нет исполнителя/жанра/лейбла |
| Контакты продавца скрыты | Телефон/email не показаны покупателю (владельцу — видны всегда) |
| В корзине уже всё доступное количество | Кнопка «В корзине (N)» заблокирована |

## Статусы товара

- **Активен** — виден в каталоге и на публичной карточке, доступен к покупке.
- **Скрыт / черновик / продан** — недоступен публично (404); владельцу доступен только через предпросмотр.
- **Удалён** — недоступен нигде.

::: warning Удаление товара
В рамках тестирование было предложено модифицировать процесс удаления товара. Сейчас удаление товара безвозвратно удаляет его с сайта, было предложение перемещать их в архивные на 30 дней, откуда в случае необходимости продавец сможет восстановить товар. Требуется уточнение по итоговой реализации данного функционала.
:::

## Правила и особенности

- **Штрих-код** на карточке **не отображается** — из идентификаторов показывается только каталожный номер. Поле штрих-кода есть в данных (берётся из релиза), но в интерфейс не выведено.
- Один и тот же релиз может продаваться разными продавцами.
- Ссылки на дискографию (исполнитель, лейбл) появляются только после подгрузки идентификатора релиза; для товаров без привязки к дискографии их нет.
- Счётчик просмотров растёт при каждом заходе, включая обновление страницы (дедупликации нет).

## Сценарии тестирования

**Окружение:** стенд `dev.muzilla.ru` (публичная страница). Доступы для действий под авторизацией (корзина/избранное/сообщения) — по запросу.

### C. Галерея

| # | Предусловия | Шаги | Ожидаемый результат |
|---|---|---|---|
| C1 | 1 фото | Открыть карточку | Стрелки перелистывания скрыты |
| C2 | Своих фото нет, есть фото релиза | Открыть карточку | Показ до 4 изображений релиза |
| C3 | Фото нет вообще | Открыть карточку | Заглушка |
| C4 | Несколько фото | Листать вперёд/назад | Перелистывание по кругу (с последнего → первое и наоборот) |

### D. Тип товара

| # | Предусловия | Шаги | Ожидаемый результат |
|---|---|---|---|
| D1 | Музыка | Открыть карточку | Есть исполнитель/жанр/стиль/лейбл/страна/формат/каталожный номер, вкладка «Содержание» |
| D2 | Hi-Fi | Открыть карточку | Бренд/категория/характеристики, **нет** вкладки «Содержание» и блоков дискографии |
| D3 | Музыка без привязки к релизу | Открыть карточку | Нет ссылок на дискографию, «Треклист не указан», исполнитель «Неизвестен» если пусто |

### E. Корзина (включая конфликты)

| # | Предусловия | Шаги | Ожидаемый результат |
|---|---|---|---|
| E1 | Гость | «В корзину» | Товар в локальной корзине, зелёный тост |
| E2 | Авторизован | «В корзину» | Товар в корзине аккаунта, зелёный тост, товар отмечен выбранным |
| E3 | Остаток 0 | Открыть карточку | Кнопка заблокирована, «Нет в наличии» |
| E4 | В корзине уже весь остаток | Нажать «В корзину» | Оранжевый тост «макс N шт», запрос не уходит |
| E5 | 2 вкладки, остаток 1, обе жмут | Одновременно добавить | Проверить поведение сервера — потенциально оба добавят (контроль на оформлении заказа) |
| E6 | Сервер отвечает ошибкой | «В корзину» | Красный тост с текстом ошибки |

### G. Написать продавцу

| # | Предусловия | Шаги | Ожидаемый результат |
|---|---|---|---|
| G1 | Гость | «Написать продавцу» | Переход в сообщения, там требование авторизации |
| G2 | Данных о продавце нет | «Написать продавцу» | Действие не срабатывает |

### H. Вкладки

| # | Предусловия | Шаги | Ожидаемый результат |
|---|---|---|---|
| H1 | Нет описания товара и продавца | Открыть карточку | Вкладки «Описание» нет, активна первая доступная |
| H2 | Есть отзывы | Клик по числу отзывов у рейтинга | Открывается вкладка отзывов, плавная прокрутка |
| H4 | В описании опасный HTML (`<script>`, `onerror=`, `javascript:`) | Открыть «Описание» | Опасные фрагменты вырезаны; проверить обход вложенными тегами |

### I. Похожие и связанные товары

| # | Предусловия | Шаги | Ожидаемый результат |
|---|---|---|---|
| I1 | У продавца есть другие товары | Открыть карточку | Блок «Другие товары продавца», ссылка «Все товары» ведёт в профиль |
| I2 | Есть товары того же исполнителя/категории | Открыть карточку | Блок «Похожие товары» (приоритет — тот же исполнитель, добор по подкатегории/категории, текущий товар исключён) |
| I3 | Нет похожих | Открыть карточку | Блок скрыт |
| I4 | В похожих/других | Проверить состав | Только допущенные к продаже, активные, с остатком и ПВЗ |
| I5 | Более 6 похожих | Листать точками-переключателями | Контент листается между похожими товарами |

### K. SEO и метаданные

| # | Предусловия | Шаги | Ожидаемый результат |
|---|---|---|---|
| K1 | Музыка | Проверить `<title>` и og:image | «Исполнитель - Название | Muzilla», og:image = первое фото |
| K2 | Hi-Fi | Проверить `<title>` | Только название |
| K3 | Товара нет | Проверить `<title>` | «Товар не найден» |

### L. Прочее

| # | Предусловия | Шаги | Ожидаемый результат |
|---|---|---|---|
| L1 | Любой активный товар | Обновить страницу N раз | Счётчик просмотров +N (дедупликации нет) |
| L2 | Продавец скрыл телефон | Открыть окно о магазине покупателем | Телефон отсутствует; владельцу — виден |
| L3 | Любой товар | Проверить строку доставки | Показывается строка доставки товара |
