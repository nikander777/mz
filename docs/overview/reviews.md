# Отзывы

> Как покупатели оценивают продавцов и товары. Отзыв оставляется **только по завершённому заказу** — как на крупных маркетплейсах, чтобы каждый отзыв был от реального покупателя (проверенная покупка). Технические детали — приложение [Техническая справка → Отзывы](/processes/reviews).

## Назначение и роли

Отзывы устроены полиморфно: один и тот же объект описывает и **отзыв о товаре**, и **отзыв о продавце**. Свободных отзывов «просто так» нет — только из заказа.

| Актор | Что может |
|---|---|
| **Покупатель** | Единственный автор. Оставляет отзывы по своему заказу (о продавце и/или о товарах), редактирует и удаляет свои отзывы. |
| **Продавец** | Является объектом отзыва. Отвечать на отзывы и оценивать покупателя **не может**. |
| **Админ / модератор** | Модерация: одобрить / отклонить / удалить, массовые действия. |
| **Гость / аноним** | Только публичное чтение. |

## Как оставляется отзыв

Из раздела «Мои заказы» у подходящего заказа — кнопка **«Оставить отзыв»** → модалка с оценкой (звёзды 1–5) и текстом. В одной модалке можно оценить продавца и каждый товар заказа сразу.

**Правила доступности (по статусу заказа):**

- Отзыв **о продавце** — если заказ **Доставлен, Завершён, Отменён или Возврат**.
- Отзыв **о товарах** — только если заказ реально получен (**Доставлен / Завершён**). Иначе покупатель видит: «Заказ не был получен, поэтому доступен только отзыв о продавце».
- Во время **спора (Disputed)**, а также в статусах Оплачен / Отправлен / В обработке отзыв **недоступен** вовсе.

Отзыв из заказа помечается как **проверенная покупка** и **публикуется сразу, без предварительной модерации**.

## Пошаговый флоу

### 1. Создание отзыва из заказа

1. Покупатель открывает завершённый заказ → модалка запрашивает список объектов для оценки (`GET /api/orders/{order}/reviews`).
2. Система проверяет право: это должен быть **покупатель заказа**, а статус — один из разрешённых (Доставлен / Завершён / Отменён / Возврат). Иначе — **403**.
3. В ответе приходят: можно ли оставлять отзыв (`can_review`), можно ли оценивать товары (`can_review_products` — только Доставлен / Завершён), блок продавца (с уже существующим отзывом для предзаполнения) и список товаров заказа.
4. Покупатель отправляет оценку продавца и/или оценки товаров (`POST /api/orders/{order}/reviews`).
5. Проверки при отправке:
   - право доступа проверяется повторно;
   - оценка 1–5, текст 10–1000 символов;
   - если не передан ни продавец, ни товары → **422** «Не переданы отзывы».
6. Сохранение идёт в одной транзакции:
   - отзыв о продавце — при передаче;
   - отзывы о товарах — только если статус разрешает; **каждый товар проверяется на принадлежность заказу** (чужие `product_id` молча отбрасываются — защита от подделки);
   - для статусов **Отменён / Возврат** товарные отзывы игнорируются (товар не получен), сохраняется только отзыв о продавце.
7. Отзыв всегда сохраняется как видимый и проверенный. **Повторная отправка того же заказа/объекта не создаёт дубль — существующий отзыв обновляется** (по связке заказ + объект стоит уникальный ключ).

### 2. Редактирование и удаление автором

- **Редактирование** (`PUT /api/profile/reviews/{review}`): доступно только автору (иначе 403). Меняются оценка и текст. Повторной модерации нет — видимость не сбрасывается.
- **Удаление** (`DELETE /api/profile/reviews/{review}`): только автор; отзыв удаляется мягко (soft delete, остаётся в БД со скрытым флагом).

### 3. Публичное чтение

- **Профиль продавца** — объединяются личные отзывы о продавце и отзывы на все его товары; в публичной выдаче учитываются только видимые отзывы, а рейтинг и счётчик берутся из кэша.
- **Карточка товара** — отзывы данного товара; рейтинг товара и счётчик считаются напрямую.

### 4. Модерация (админка)

- **Одобрить** — делает отзыв видимым, ставит дату публикации, пишет запись в журнал действий, сбрасывает кэш рейтингов.
- **Отклонить** — скрывает отзыв и обнуляет дату публикации; такой отзыв попадает в раздел «Ожидающие».
- **Массовое одобрение / отклонение** — обновляет отзывы пакетом.
- **Удалить** — мягкое удаление + запись в журнал.

## Уведомления

| Событие | Кому | Канал |
|---|---|---|
| Новый / одобренный / отклонённый отзыв | — | **Нет** |

Событийных уведомлений по отзывам (push / email / Telegram / Max) система **не шлёт**. Единственный побочный эффект сохранения отзыва — пересчёт кэша агрегированного рейтинга продавца (с дебаунсом ~30 сек).

## Где видны

- На карточке товара — вкладка «Отзывы».
- В профиле магазина — вкладка «Отзывы (N)»: личные отзывы о продавце + отзывы на его товары.
- В кабинете продавца — «Отзывы».
- У покупателя — «Мои отзывы» (редактирование / удаление).
- На общей странице «Отзывы пользователей» и в общей статистике распределения оценок.

## Фильтр по оценке

Над списком отзывов — вкладки «Все отзывы», «5 звёзд», «4 звезды» и так далее. Вкладка появляется только если отзывы с такой оценкой есть; если оценка всего одна, вкладки не показываются вовсе — они дублировали бы «Все отзывы».

Счётчики вкладок считаются по всем видимым отзывам, а не по текущей выборке: после выбора «4 звезды» остальные вкладки остаются на месте. Скрытые модерацией отзывы не попадают ни в список, ни в счётчики.

## Ответ продавца

Продавец может один раз ответить на каждый отзыв — о нём самом или о его товаре. Ответ показывается под отзывом блоком «Ответ продавца» и виден всем.

| Правило | Как работает |
|---|---|
| Кто может отвечать | Только продавец, которому адресован отзыв: он сам (отзыв о продавце) или владелец товара. Чужой отзыв → 403 |
| Сколько ответов | Один на отзыв; повторная отправка перезаписывает текст |
| Изменение и удаление | Продавец правит и удаляет свой ответ в любой момент |
| Длина | От 10 до 2000 символов |
| Мат | Отклоняется тем же фильтром, что и текст отзыва (см. [Правила и особенности](#правила-и-особенности)) |
| Модерация | Ответ не отправляет отзыв на перемодерацию и не меняет рейтинг |

Ответить можно из кабинета продавца → «Отзывы». Администратор может ответить за магазин из админки — ответ пишется в то же поле.

## Все сценарии и крайние случаи

| Ситуация | Что происходит |
|---|---|
| Заказ **Доставлен / Завершён** | Доступны отзывы и о продавце, и о товарах. |
| Заказ **Отменён / Возврат** | Доступен только отзыв о продавце; товарные отбрасываются (товар не получен). |
| Заказ **Отправлен / Оплачен / В обработке / Спор** | Отзыв недоступен, попытка → 403. Спор блокирует отзыв намеренно. |
| Чужой `product_id` в списке товаров | Молча пропускается, свои сохраняются. |
| Повторная отправка того же объекта | Существующий отзыв обновляется, дубля нет. |
| Пустая отправка (ни продавца, ни товаров) | 422 «Не переданы отзывы». |
| Текст короче 10 или длиннее 1000 символов | 422 (валидация). |
| Оценка вне 1–5 | 422 (валидация). |
| Удаление автора | Его отзывы удаляются каскадно. |
| Удаление заказа | Отзыв остаётся, но связь с заказом обнуляется (теряется отметка «проверенная покупка»). |
| Скрытие ФИО (`hide_fio`) | Гостю ФИО не показывается, имя/название — всегда; автору видно всё. |
| Легаси-отзывы (из старой системы) | Без связи с заказом, `verified_purchase = false`; учитываются в рейтинге. |

## Статусы отзыва

| Признак | Значение |
|---|---|
| Видим (`is_visible`) | Опубликован и показывается публично. |
| Скрыт | Отклонён модератором или удалён мягко; в профиле продавца не показывается. |
| Проверенная покупка | Отзыв создан из заказа (у легаси — нет). |
| Ожидает модерации | Скрыт и без даты публикации — раздел «Ожидающие» в админке. |

## Правила и особенности

- Отзыв создаётся **только из заказа** — свободных отзывов нет.
- Один заказ → отзыв о продавце и по одному отзыву на каждый его товар; повторная отправка обновляет, а не плодит.
- Отзывы из заказа публикуются сразу, модерация возможна только постфактум (отклонить).
- Рейтинг продавца объединяет отзывы о самом продавце и о его товарах.
- Показываются средняя оценка и количество отзывов; в статистике доступно распределение по звёздам 1–5.

## Техническая часть

Полиморфные отзывы (продавец / товар), гейтинг по статусу заказа, upsert по связке «заказ + объект», модель модерации — приложение [Техническая справка → Отзывы](/processes/reviews).
