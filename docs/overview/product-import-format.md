# Формат файла для загрузки лотов

> Описание структуры файла, которым продавец выгружает и загружает свои лоты. Сам процесс — в разделе [Работа с товарами](/overview/seller-products). Технические детали — приложение [Техническая справка → Продажа товара](/processes/seller-listing).

::: warning Есть публичная версия этой страницы
Продавцы читают тот же текст на сайте: `/help/product-import-format` (`nuxt/pages/help/product-import-format.vue`) — именно туда ведёт ссылка из окна импорта. Правки формата вносите в оба места. Источник истины самого формата — `main/app/Support/ProductSheetSchema.php`.
:::

## Как этим пользоваться

Основной сценарий — **обновление своих лотов**:

1. В кабинете продавца → **Мои лоты** → **Экспорт**. Выгрузится файл со всеми лотами; в первой колонке — ID лота.
2. Поправьте нужные значения в Excel: цену, наличие, статус, описание.
3. **Импорт** → выберите тот же файл. Изменения применятся к лотам по ID — перепутать карточки невозможно.

Второй сценарий — **перенос лотов с другой площадки**. Автоматической выгрузки с «Мешка» и других площадок нет: скачайте свои лоты у них, приведите файл к структуре ниже (проще всего — взять наш **шаблон** по ссылке в окне импорта) и загрузите. Строки без ID создадут новые лоты.

::: warning Загрузка не удаляет лоты
Файл может создавать и обновлять лоты, но не удаляет их. Лот, которого нет в файле, останется как был.
:::

## Структура книги

Файл — книга Excel из трёх листов:

| Лист | Что внутри |
|---|---|
| **Товары** | Данные. Первая строка — заголовки, её удалять нельзя |
| **Справочники** | Допустимые значения для колонок-справочников |
| **Инструкция** | Те же правила, что и на этой странице |

Принимаются `.xlsx`, `.xls` и `.csv`. Ограничения: **до 10 МБ** и **до 5000 строк** за раз, одновременно обрабатывается **одна** загрузка.

## Правила заполнения

| Правило | Что означает |
|---|---|
| **Колонка `id` пустая** | Будет создан новый лот |
| **Колонка `id` заполнена** | Обновится существующий лот |
| **Ячейка пустая** | Значение **не меняется** (при обновлении) |
| **В ячейке `-`** | Поле очищается |
| **Чужой ID** | Строка отклоняется, чужой лот не затрагивается |
| **Колонка отсутствует** | Поле не меняется — можно оставить в файле только нужные колонки |

Заголовки можно писать латиницей (`price`) или русской подписью (`Цена, ₽`), регистр не важен.

::: tip Повторная загрузка того же файла
Если в строке нет ID, но заполнены `source` и `source_id`, лот ищется по этой паре. Так повторная загрузка выгрузки с другой площадки не создаёт дубли.
:::

## Колонки

### Обязательные при создании лота

| Колонка | Название | Тип | Пример |
|---|---|---|---|
| `title` | Название | текст, до 295 символов | `Pink Floyd — The Wall` |
| `price` | Цена, ₽ | число | `2500` или `1 500,50` |
| `stock_quantity` | Наличие, шт | целое | `1` |
| `category` | Категория | справочник | `music` |
| `condition` | Состояние | справочник | `used` |

При создании лот попадает в **черновики** — опубликовать его можно колонкой `status` или из карточки.

### Состояние и грейды

| Колонка | Название | Значения |
|---|---|---|
| `media_grade` | Грейд носителя | `M`, `NM`, `VG+`, `VG`, `G+`, `G`, `F`, `P` |
| `sleeve_grade` | Грейд обложки | те же + `Generic` |
| `device_grade` | Состояние техники | `ok`, `used`, `repair` (только Hi-Fi) |
| `color` | Цвет пластинки | `black`, `colored`, `special` |

Грейды носителя и обложки обязательны, когда состояние — `used`. Для обложки есть отдельное значение `Generic` — типовой конверт без оригинальной печати.

### Данные релиза

`artist`, `release_format`, `release_label`, `release_catno`, `release_country`, `release_year`, `release_genre`, `release_style` — заполняются вручную и работают в фильтрах каталога.

`discogs_release_id` — необязателен. Если указать, метаданные подтянутся из дискографии.

### Остальные колонки

| Колонка | Название | Примечание |
|---|---|---|
| `status` | Статус | `active`, `inactive`, `draft` |
| `subcategory` | Подкатегория | Название из справочника |
| `description` | Описание | |
| `weight` | Вес, г | Влияет на расчёт доставки |
| `location` | Местоположение | |
| `pickup_point` | Индекс ПВЗ отправки | Почтовый индекс **вашего** пункта отправки |
| `shipping_cost` | Стоимость доставки, ₽ | |
| `can_trade` | Торг уместен | `да` / `нет` |
| `brand` | Бренд | Для Hi-Fi; новый бренд заводится автоматически |
| `common_properties` | Характеристики | |
| `youtube_link` | Ссылка YouTube | |
| `source`, `source_id` | Источник и ID в нём | Для переноса с другой площадки |

### Только для чтения

`id`, `slug`, `updated_at`, `photos` — выгружаются для справки, при загрузке игнорируются.

::: warning Фотографии через файл не загружаются
В выгрузке колонка `photos` содержит ссылки на уже загруженные снимки. Добавить фото можно только в карточке лота.
:::

## Справочники

**Категория (`category`)**: `music` — Музыка, `hifi` — Hi-Fi аппаратура.

**Состояние (`condition`)**: `new` — Новый, `used` — Б/У, `collectible` — Коллекционный.

**Статус (`status`)**: `active` — В продаже, `inactive` — Снят с продажи, `draft` — Черновик.

Статусы «Продан» и «Удалён» ставит система. В выгрузке они встречаются — это нормально, при загрузке такие строки просто не меняют статус.

**Цвет (`color`)**: `black` — Чёрный, `colored` — Цветной, `special` — Спецэффекты.

**Грейды** — шкала Discogs: `M` (Mint), `NM` (Near Mint), `VG+` (Very Good Plus), `VG` (Very Good), `G+` (Good Plus), `G` (Good), `F` (Fair), `P` (Poor).

## Что делать с ошибками

Плохие строки не отменяют весь файл: корректные применяются, а по остальным формируется отчёт. В окне импорта появится **«Скачать отчёт об ошибках»** — в нём указаны номер строки, колонка, значение и причина.

Частые причины:

| Сообщение | Что делать |
|---|---|
| Лот с таким ID не найден среди ваших | Проверьте ID — он должен быть из вашей выгрузки |
| «Цена»: не похоже на число | Уберите текст и валюту, оставьте только число |
| Для состояния «used» нужен грейд носителя | Заполните `media_grade` |
| Для состояния «used» нужен грейд обложки | Заполните `sleeve_grade` |
| «Категория»: допустимо только music или hifi | Впишите код из справочника |
| «Индекс ПВЗ отправки»: среди ваших пунктов такого индекса нет | Сверьтесь со списком своих пунктов отправки |

::: tip Сначала проверьте файл
В окне загрузки есть галочка **«Только проверить файл, ничего не менять»**. Она прогоняет файл целиком и показывает все ошибки, не трогая лоты.
:::
