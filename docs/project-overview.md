## 1. Что такое MUZILLA

**Музыкальный маркетплейс** (винил/CD и др. носители) с мультивендорной моделью:
продавцы (частные лица, ИП, магазины) выставляют товары, покупатели оформляют заказы
с онлайн-оплатой и доставкой по РФ.

Каталог построен на интеграции с **Discogs** — крупнейшей базой музыкальных релизов
(~19 млн релизов). Поверх каталога работают карточки товаров, поиск, фасетная
фильтрация, корзина, оформление заказа, платежи и доставка.

## 2. Технологический стек

### Backend
- **PHP 8.2+** (в проде — образы на PHP 8.4)
- **Laravel 12** — основной фреймворк
- **Laravel Sanctum 4** — аутентификация (stateful SPA + API-токены)
- **Inertia.js 2** — связка Laravel ↔ Vue для внутренних интерфейсов
- **Laravel Reverb 1.5** — WebSocket-сервер (realtime: уведомления, диалоги)
- **Laravel Scout 10 + Meilisearch** — полнотекстовый поиск
- **Laravel Socialite** — OAuth (вход через VK ID)
- **Pest** — тестирование

### Frontend
- **Основной клиент (`nuxt`):** Nuxt 3.17 + Vue 3.5, TypeScript, PrimeVue 4 + Nuxt UI 3,
  Pinia (состояние), nuxt-auth-sanctum (auth), Editor.js (контент), vue-yandex-maps (карты),
  Tailwind CSS. Тесты — Vitest. Отдельное приложение (SSR/SPA), потребляет API бэкенда.
- **Внутренние интерфейсы (`main`/`discogs`):** Vue 3.5 + Inertia 2, Tailwind CSS 4,
  Reka UI, Lucide (иконки), сборка Vite.

### Серверная часть / инфраструктура
- **Docker + Docker Compose** — контейнеризация всех сервисов
- **GitHub Container Registry (GHCR)** — хранение образов
- **GitHub Actions** — CI/CD (сборка образа → push в GHCR → авто-деплой по SSH)
- **Nginx 1.27** (edge reverse-proxy) + **Caddy** (HTTPS, авто-сертификаты Let's Encrypt)
- **PostgreSQL 17** — основная БД
- **Redis 7** — кэш, сессии, очереди, брокер для Reverb
- **Meilisearch v1.6** — поисковый движок
- **MinIO** + **Timeweb S3 (Object Storage)** — хранение изображений/медиа
- **Node.js 20** — рантайм для Nuxt SSR

## 3. Архитектура

Проект состоит из **трёх независимых сервисов** в одном репозитории:

| Сервис | Назначение |
|--------|-----------|
| **main** | Основной бэкенд: аутентификация, пользователи, товары, заказы, платежи, доставка, корзина, чаты. Laravel 12 + Vue/Inertia. |
| **discogs** | Специализированный сервис каталога: импорт и отдача данных Discogs (~19M релизов), обработка изображений. Облегчённый Laravel 12. |
| **nuxt** | Клиентское приложение (витрина, личные кабинеты, админка). Nuxt 3, общается с `main`/`discogs` по API. |

Связь: `nuxt` (фронт) → API `main` и `discogs` (бэкенды) → PostgreSQL / Redis / Meilisearch / S3.
Realtime-события идут через Reverb (WebSocket).

Подробнее об архитектуре и модулях — [`architecture/overview.md`](architecture/overview.md).

## 4. Мощности серверов

### Production — 3 выделенные машины (разделение по ролям)

| Узел | Роль | Характеристики | Хостинг |
|------|------|----------------|---------|
| **Edge** | HTTPS-терминация (Caddy), reverse-proxy (nginx), Nuxt SSR, оба Laravel-бэкенда (FPM) | 4 vCPU / 8 ГБ RAM / 80 ГБ SSD | VDS (Selectel) |
| **App** | Redis, Reverb (WebSocket), очереди и шедулеры (фоновые задачи, обработка изображений) | 4 vCPU / 8 ГБ RAM / 40 ГБ + доп. диск 147 ГБ | VDS (Selectel) |
| **Data** | PostgreSQL 17, Meilisearch, MinIO, бэкапы | Dedicated (Intel Xeon E-2388G), **128 ГБ RAM / 4 ТБ** | Timeweb |

Выделенный data-узел (128 ГБ RAM) обусловлен объёмом каталога Discogs (десятки
миллионов записей) и поисковым индексом.

### Staging
- **1 VPS** (single-host) — все сервисы на одной машине, для smoke-тестов перед продом.

### Окружения
| Окружение | Домен |
|-----------|-------|
| Production | `muzilla.ru` |
| Staging | `dev.muzilla.ru` |

## 6. Масштаб проекта

### Строки кода (собственный код, без зависимостей)

| Сервис | Строк (≈) | Профиль |
|--------|-----------|---------|
| main | 91 500 | PHP-бэкенд + Vue/Inertia |
| discogs | 20 700 | PHP-бэкенд + Vue/Inertia |
| nuxt | 94 000 | Vue + TypeScript (фронт) |
| **Итого** | **≈ 206 000** | application-код |

Исключены зависимости (`vendor/`, `node_modules/`), сборки и legacy-каталог.

> Уточнение: это **физические** строки (включая комментарии и пустые). «Чистых»
> строк кода обычно на 25–35% меньше — ориентир **≈ 140–150 тыс. строк кода**.

### Данные и нагрузка (для оценки масштаба)
- Каталог Discogs: **~19 млн** релизов, ~9 млн исполнителей, ~2 млн лейблов
- Перенос данных со старого портала: миллионы пользователей / товаров / заказов / отзывов

## 7. E-commerce: что уже реализовано

Ключевые узлы для дальнейшего развития E-commerce:

- **Платежи** — Moneta.ru: оплата заказов, СБП по QR, транзитная схема расчётов
  (покупатель → площадка → продавец), выплаты продавцам, регистрация продавцов как ЮЛ/ИП.
- **Доставка** — Почта России: тарифы, оформление отправлений, трекинг, выбор ПВЗ;
  карта доставки на Yandex Maps; подсказки адресов через DaData.
- **Каталог** — мультивендорный, на базе Discogs (~19M релизов), поиск (Meilisearch),
  фасетная фильтрация.
- **Корзина и оформление заказа** — серверная корзина (REST API), чекаут с выбором
  доставки и оплаты.
- **Заказы, отзывы, избранное, продавцы/магазины** — реализованы (в т.ч. перенос с
  legacy-портала).
